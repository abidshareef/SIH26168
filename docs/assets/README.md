# NAV-AION README assets

This directory contains the visual assets used by the NAV-AION project README.

- `hero.svg` — NAV-AION identity and system summary
- `architecture.svg` — NAV-AION navigation architecture
- `workflow.svg` — GNSS outage, dead reckoning and recovery workflow

Benchmark figures should be generated from real experiment outputs and committed only after the corresponding metrics have been produced by the evaluation pipeline. Do not place synthetic performance claims in benchmark figures or documentation.
