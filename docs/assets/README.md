# NavIQ README assets

This directory contains visual assets used by the project README.

- `hero.svg` — project identity / system summary
- `architecture.svg` — high-level navigation architecture
- `workflow.svg` — GNSS outage → dead reckoning → recovery workflow

Benchmark figures should be generated from real experiment outputs and committed here only after the corresponding metrics have been produced by the evaluation pipeline. Do not place synthetic performance claims in the benchmark section.
